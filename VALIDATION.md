## Полные симуляции

Сырые результаты: `tests/results/normal.json`, `tests/results/modes.json`. Общий бот выбирает улучшения, собирает XP и уклоняется; бессмертие и принудительные убийства в этих симуляциях не используются. Для теста босс-раша используется сохранение с уже открытым режимом. Лимит длительного сценария — 2400 секунд игрового времени.

- Normal, пять начальных сохранений: **5/5 побед**, 731 / 863 / 723 / 798 / 739 секунд, 1168–1418 убийств.
- Endless, три сборки, реально продолженные после Normal: **708 / 1342 / 1348 секунд Endless**, затем смерть с сохранённой победой; 4 / 12 / 11 боссов Endless. Максимум 242 врага (240 обычных слотов плюс два плановых босса), максимум 319 снарядов.

Это воспроизводимая проверка игрового цикла, а не доказательство окончательного баланса для всех игроков.

## Статическая публикация и ограничения

Все игровые ресурсы локальные, импорты относительные, атласы адресуются относительно `import.meta.url`. Нет CDN, API-ключей, платных зависимостей или 3D-моделей в runtime. В GitHub Pages необходимо загрузить папки `assets`, `css`, `js`, `index.html`, `.nojekyll`.

Внешние модели из ТЗ **не интегрированы**: фактические страницы основных источников недоступны, подходящие скачивания альтернатив не подтверждены. Вместо них поставляются собственные параметрические модели и протестированный Python-конвейер. Blender не установлен и не использован. Полный журнал источников — `tools/assets-manifest.json`; кредиты относятся только к действительно поставляемым ресурсам.

Текущая сборка забега не восстанавливается после перезагрузки, как и в v1. Уже записанные победы, открытые режимы, валюта и рекорды сохраняются. GitHub не обновлялся: локальная папка не содержит `.git`.
