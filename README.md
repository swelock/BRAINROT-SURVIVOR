# BRAINROT SURVIVORS

Законченный игровой цикл браузерного roguelite: выберите героя, переживите 15 волн, победите финального босса и вложите заработанную ДНК в постоянные улучшения. Русский язык включён по умолчанию; English доступен в настройках.

## Запуск

Проект работает как статический сайт: без backend, аккаунтов, API-ключей, сборки и внешних библиотек. Графика рисуется Canvas, музыка и эффекты синтезируются Web Audio. Все ресурсы находятся в проекте, внешних сетевых запросов нет.

**Самый простой способ на macOS:** дважды нажмите `start.command`. Нужен установленный Python 3. Скрипт откроет игру в браузере на свободном локальном порту. Оставьте окно терминала открытым; Ctrl+C остановит предпросмотр.

**Через терминал на любой системе:** откройте папку проекта и выполните:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

На Windows команда может называться `py -m http.server 8000 --bind 127.0.0.1`. Откройте <http://localhost:8000>.

Локальный HTTP нужен только для загрузки ES-модулей браузером; игрового сервера нет. Открытие `index.html` через `file://` блокирует модули в большинстве браузеров. После публикации достаточно обычной ссылки.

## Управление

- WASD или стрелки — движение. Используются физические коды клавиш: русская раскладка тоже работает.
- Пробел или любой Shift — рывок в направлении движения; в покое — в последнем направлении.
- Esc — пауза / продолжение; выход из вспомогательных меню.
- 1, 2, 3 — выбор карточки при повышении уровня.
- На сенсорном экране — левый виртуальный стик и правая кнопка рывка.
- Атаки и наведение автоматические. Подбирайте голубые кристаллы опыта и касайтесь сундуков.

Переключение на другую вкладку автоматически ставит забег на паузу. Рывок длится 0,18 сек., преодолевает 150 единиц без бонусов и кратко защищает от урона. Диагональное движение нормализовано.

## Содержимое

- **5 героев:** Тунг Тунг Тунг Сахур, Тралалеро Тралала, Бомбардиро Крокодило, Балерина Капучина и секретный Абсолютный Брейнрот. Первые четыре доступны сразу; пятый открывается при достижении волны 12. У каждого своя пассивная способность.
- **15 волн по 45 секунд**, переходы по 3 секунды. На волнах с боссом переход ждёт его поражения. Победа наступает при убийстве финального босса; бежать до конца таймера после этого не нужно.
- **6 типов врагов:** дубинщики, бегуны, стрелки, танки, подрывники, странные типы. С волны 8 встречаются элиты: быстрые, крепкие, токсичные, взрывающиеся и регенерирующие.
- **3 основных босса:** Большой Дубинщик на волне 5, Разрушитель Реальности на волне 10, Абсолютный Брейнрот на волне 15. Дополнительный мини-босс Странный Тип — на волне 9. Финальный босс имеет три фазы, рывок, залпы, призыв, дождь снарядов и смену реальности. Опасные атаки заранее обозначаются.
- **7 видов оружия**, до 6 одновременно, 8 уровней каждого: Базовая рвота, Токсичный спрей, Ядерная рвота, Радужная рвота, Взрывная отрыжка, Орбита брейнрота, Сигма-волна.
- **5 эволюций:** Рвота апокалипсиса, Токсичный шторм, Снаряд судьбы, Абсолютная радуга, Галактический брейнрот.
- **31 улучшение забега**, четыре редкости, ограниченные стеки и ровно три варианта на повышение уровня.
- **12 временных усилений**, сундуки раз в 60–90 секунд до бонусов. Повторное усиление обновляет таймер, разные усиления сочетаются.
- **Множители урона:** ×2, ×3, ×5, ×10, ×25, ×50, ×100, ×666, ×1000. Последние очень редки. Новый более слабый множитель не понижает текущий.
- **38 постоянных узлов**, пять ветвей, три завершающих способности. Дерево можно прокручивать или перетаскивать; узлы показывают эффект, цену, требование и состояние покупки.
- Пять визуальных состояний бескрайней процедурной арены, следы рывка, частицы, числа урона, музыка, отдельные регуляторы громкости, отключаемая тряска.
- Статистика, рекорды, награды, повторные забеги, сохранение в LocalStorage.

## Эволюции

Доведите оружие до уровня 8 и получите подходящее пассивное улучшение. На следующем повышении уровня эволюция появится среди трёх вариантов.

- Базовая рвота + Токсичный желудок → Рвота апокалипсиса: яд и взрывы.
- Токсичный спрей + Биоугроза → Токсичный шторм: замедляющие ядовитые зоны.
- Ядерная рвота + Взрывное пищеварение → Снаряд судьбы: крупные и вторичные взрывы.
- Радужная рвота + Удачливый желудок → Абсолютная радуга: несколько эффектов в одном снаряде.
- Орбита брейнрота + Орбитальный хаос → Галактический брейнрот: усиленные спутники с выстрелами.

Токсичный желудок, Взрывное пищеварение и Удачливый желудок могут быть заранее открыты в постоянном дереве. Пассивные улучшения также доступны внутри забега, поэтому эволюции возможны без покупки мета-узлов.

## Сохранения и награды

Один объект `brainrot-survivors-v1` в LocalStorage хранит версию, ДНК, покупки, секретного героя, статистику и настройки. Текущий незавершённый забег не сохраняется. Перезагрузка страницы прервёт его; завершайте через паузу, чтобы получить награду.

Базовая награда: `10 + достигнутая волна + floor(убийства / 50) + 25 × боссы`. Победа добавляет 50 ДНК, затем применяются бонусы постоянного дерева. Начисление происходит один раз, при победе, смерти или завершении забега из паузы.

Прогресс зависит от браузера и адреса сайта, включая порт. Для повторной игры с тем же сохранением используйте одинаковый адрес. Локальный запуск через `python3 -m http.server 8000` задаёт постоянный порт; `start.command` предпочитает порт 8000 и использует свободный, если он занят. Сохранение с другого адреса автоматически не переносится. При недоступном LocalStorage игра продолжает работать в памяти и показывает предупреждение.

Неизвестная будущая версия или повреждённый JSON безопасно заменяется начальными данными в памяти; игра не падает. Удаление данных сайта в браузере сбрасывает прогресс. Внутри игры нет кнопки необратимого сброса.

## Структура проекта

```text
brainrot-survivors/
├── index.html
├── .nojekyll
├── README.md
├── VALIDATION.md
├── start.command
├── start.py
├── package.json
├── css/
│   └── style.css
├── js/
│   ├── main.js                    # загрузка, ввод, фиксированный шаг, автопауза
│   ├── data/
│   │   ├── catalog.js             # герои, враги, оружие, эффекты, локализация
│   │   └── meta.js                # дерево, связи, цены, правила покупки
│   ├── game/
│   │   ├── Game.js                # состояние забега, волны, XP, бой, награды
│   │   ├── Renderer.js            # арена, камера, персонажи, снаряды и эффекты
│   │   └── math.js                # геометрия, случайные выборки, spatial grid
│   ├── systems/
│   │   ├── EnemySystem.js         # спавн, AI, элиты, боссы и предупреждения
│   │   ├── WeaponSystem.js        # семь атак, снаряды и пять эволюций
│   │   ├── UpgradeSystem.js       # три выбора, редкости, ограничения, бонусы
│   │   ├── SaveSystem.js          # LocalStorage, версии, статистика, ДНК
│   │   └── AudioSystem.js         # синтез музыки и эффектов
│   └── ui/
│       └── UIManager.js           # меню, герои, дерево, HUD, настройки, результаты
└── tests/
    ├── game.test.js               # проверки симуляции без браузера
    └── balance.mjs                 # пять полных забегов с ботом
```

Игровая симуляция отделена от DOM и отрисовки. Персонаж содержит базовые параметры, бонусы, оружие и улучшения; оружие — ID, уровень, таймер и флаг эволюции. Враги, снаряды, зоны, сундуки и кристаллы хранятся в массивах сущностей. Временные усиления — словарь `ID → оставшееся время`. Запросы столкновений используют пространственную сетку. Частицы, снаряды, зоны и числа урона ограничены; далёкие снаряды и мёртвые сущности удаляются. Скопившийся опыт объединяется без потери ценности.

Для нового персонажа добавьте запись в `characters`, его рисунок в `drawCharacter` и пассивную способность в `WeaponSystem`. Для нового бонуса добавьте запись в каталог и обработку соответствующего параметра симуляцией.

## GitHub Pages

1. Создайте репозиторий GitHub.
2. Загрузите **содержимое** этой папки: `index.html` должен лежать в корне выбранной папки публикации.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку с проектом и папку **/(root)**, нажмите **Save**.
6. Дождитесь завершения публикации и откройте адрес, показанный GitHub Pages.

Все ссылки на ресурсы относительные, поэтому игра поддерживает адреса вида `https://имя.github.io/репозиторий/`. Никаких секретов, npm install или build не требуется. Файл `.nojekyll` отключает обработку Jekyll. Python-скрипты и тесты для работы опубликованной игры не нужны; при желании можно публиковать только `index.html`, `.nojekyll`, `css/`, `js/`.

## Проверка и решения по неоднозначностям ТЗ

При установленном Node.js:

```sh
npm test
```

Это запускает встроенный `node:test`, сторонние зависимости не нужны. Результаты проверок перечислены в `VALIDATION.md`.

- У базового снаряда изначально нет пробития: он исчезает после первого попадания. На уровне 6 появляется ещё одно попадание.
- «Азарт» иногда заменяет один из трёх вариантов легендарным, сохраняя требование ровно трёх карточек.
- В ТЗ перечислены 25 основных улучшений, но требуется минимум 30. Добавлены пять эволюционных пассивов и одно легендарное улучшение, итого 31.
- Постоянное дерево содержит 38 узлов, соответствующих перечисленным ветвям и трём завершающим способностям.
- Волна 9 содержит дополнительного мини-босса согласно расписанию волн.
- Бескрайняя арена не имеет твёрдых краёв; декорации не блокируют движение.
- Это самостоятельная игровая графика и синтезированная музыка, без заимствованных изображений и аудиозаписей мемов.
